# 💫 About Me:
Mobile-first software engineer with **4 years of experience** designing and shipping production-grade Android and iOS applications using React Native, JavaScript, and TypeScript. Proven ability to integrate REST APIs, WebSockets, real-time features, AI-powered functionalities, Bluetooth (BLE) services, payment solutions (Square SDK), and deep linking (Branch.io) into high-performance cross-platform mobile experiences. Familiar with Node.js, MongoDB, Firebase, and Expo, with hands-on experience supporting backend development and API integration. Experienced in Agile/Scrum workflows, code reviews, and CI/CD pipelines. A collaborative team player driven by writing clean, testable, and maintainable code.
